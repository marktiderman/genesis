A WCAG contrast check for brands. `validateBrand` returns `warnings` for every theme role pair the brand changes that falls under its minimum (4.5:1 for text, 3:1 for fills, the focus ring and status marks; text on a fill only where genesis-ui draws `*-foreground` on it, so the Genesis brand reports none) and for every `extensions` color against the text drawn on it: a scale's new optional `foreground` stop, or else the brand's text and surface colors. `ok` stays true for them, so an existing brand keeps building; only body text under 1.5:1 on its page is an error. `brandContrastProblems(brand)` returns the same findings as data. `BrandValidationResult.warnings` is optional: the `./schema/brand` entry's `validateBrand` stays the light shape check and adds contrast only when passed `{ contrast: brandContrastProblems }`. `createGenesisNativewindPreset({ brand })` also makes the brand's extension colors classes, under the kebab-case names `tailwindFromBrand` gives them on web (`bg-game-mode-solo`).
