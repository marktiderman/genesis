The optional `@puckeditor/core` peer now accepts 0.24 as well as 0.23 (`^0.23.0 || ^0.24.0`), and the package builds and tests on 0.24.0. Puck 0.24 lists no breaking changes (new field types, field groups and tabs, an opt-in drag handle, and fixes), so an app on 0.23 keeps working and can move to 0.24 when it likes.
