`InboxRowMenu`: a row's actions as the web offers them, a More button opening a menu (destructive items in red). It's the twin of the phone's swipe and long-press menu. InboxPage's default row draws it, and a row of your own (the `row` slot) draws it the same way. Each item is `<testID>-action-<id>`, unchanged.
