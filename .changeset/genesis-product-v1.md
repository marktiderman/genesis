New, private package: the product system's first version, used on this repo first. `genesis-product board` lays out features.ts as a Now / Next / Later board with the top ideas by demand and a triage inbox (as markdown, or the repo's "Product board" issue); `genesis-product release --from <ref>` drafts release notes for what reached beta or live and, with `--notify`, closes the issues it answers. Ideas and feedback come from GitHub issue forms behind a `SignalSource` contract.

Features: product-roadmap, product-insights, product-releases
