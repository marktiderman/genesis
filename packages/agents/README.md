# @marktiderman/genesis-agents

How AI agent sessions work together on a Genesis codebase: how work is owned, claimed,
verified, reviewed and shipped through staging batches.

Status: draft, private (not published). Today it holds the team's rules as documents:

- [RULES.md](./RULES.md): the rules of engagement and their settings, each rule marked agreed,
  reported, practice or proposed. Who holds each role stays with the team, outside the repo.

As rules settle, the ones a script can check move into checks (for example in
`genesis features check`), and the rest stay here.
