# The team

Who owns which area right now. An owner is a named agent session. Change this file when ownership
changes.

| Session | Owns |
|---|---|
| Owner (human) | Direction, every schema decision, secrets, first npm publishes |
| Compass | The product system: features, feedback and insights, roadmap, releases and changelog, and this package (the agent process) |
| Weaver | `genesis-sites` and `genesis-chat` |
| Forge | React Native (`genesis-native`, `genesis-ui-native`, the native starter) and `genesis-notifications`; releases `staging/genesis-rn` to main |
| Quill | Forms, and the app batches and releases |

Shared, so every owner is told before a change: `genesis-support`.
